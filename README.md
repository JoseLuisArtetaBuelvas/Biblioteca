# Biblioteca - Gestion de prestamos con Lista, Cola y Pila

Actividad Unidad 2 de Estructuras de Datos (Universidad de Cartagena).
Ejercicio 3: Biblioteca. Entidad principal `LibroPrestamo`, identificada por el codigo de prestamo.

Aplicacion Java de consola que usa estructuras de datos propias basadas en nodos enlazados:

- **Lista**: registro general de todos los prestamos.
- **Cola**: solicitudes de prestamo pendientes por entregar (FIFO).
- **Pila**: historial de prestamos entregados, que permite deshacer la ultima entrega (LIFO).
